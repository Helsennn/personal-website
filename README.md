# Haoze Ni — Personal Website

A mobile-first, static portfolio for GitHub Pages. The site uses plain HTML, CSS, and JavaScript—no build step or framework required.

## Preview locally

```bash
python3 -m http.server 4177
```

Then open `http://127.0.0.1:4177/`.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. Open **Settings → Pages** in the repository.
3. Choose **Deploy from a branch**.
4. Select the main branch and the `/ (root)` folder.

## Files

- `index.html` — page content and SEO metadata
- `styles.css` — mobile-first visual system and responsive layout
- `script.js` — portrait switching, mobile navigation, swipe, and reveal motion
- `assets/images/` — original and generated portrait assets
